# Database connection ledger

Each row is one production connection acquisition site. `Shared` blocks an archive writer while open; `exclusive` blocks every other archive process. `Archive` cardinality means the work can grow with the whole archive even when its returned result is small. Every acquisition is reconciled against this ledger by `tests/test_database_connections.py`; the normative rules are in `database-connections.md`.
