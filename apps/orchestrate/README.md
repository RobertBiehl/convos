# convos-orchestrate

A keyboard-first agentic IDE for [Convos](https://github.com/RobertBiehl/convos). Every agent
session reports items with statuses, results, threads, and questions; you steer them from one
board in your browser.

```bash
uv tool install convos --with convos-orchestrate --prerelease allow   # beta: only pre-releases exist
convos orchestrate install   # /orchestrate for Claude Code, $orchestrate for Codex
convos orchestrate open      # the IDE in your browser
```

This is a beta. See the [full documentation](https://github.com/RobertBiehl/convos/blob/master/docs/orchestrate.md).
